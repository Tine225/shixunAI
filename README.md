# 电商图片提取下载

Chrome 浏览器扩展：在淘宝、京东、拼多多商家版商品详情页一键提取图片，预览后选择下载为 PNG。

## 功能

- 详情页右下角「获取图片」浮动按钮
- 自动提取主图、SKU 图、详情图等
- 新标签页网格预览，支持全选 / 取消 / 单选
- 选中图片统一转为 **PNG** 格式下载到本地文件夹

## 支持平台

| 平台 | 域名示例 |
|------|----------|
| 淘宝 / 天猫 | `item.taobao.com`、`detail.tmall.com` |
| 京东 | `item.jd.com` |
| 拼多多商家版 | `mms.pinduoduo.com`（商品编辑/详情相关页） |
| 拼多多商品页 | `yangkeduo.com` 等 |

## 安装（开发者模式）

1. 打开 Chrome，地址栏进入 `chrome://extensions/`
2. 开启右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本项目根目录（含 `manifest.json` 的文件夹）

## 使用

1. 打开支持的商品详情页
2. 点击右下角 **获取图片**
3. 在新打开的预览页勾选需要的图片
4. 点击 **下载选中**，图片会以 PNG 保存（按商品标题建文件夹）

## 目录结构

```
├── manifest.json
├── background/background.js   # 打开预览页、拉取图片并转 PNG 下载
├── content/
│   ├── content.js             # 浮动按钮
│   ├── content.css
│   └── extractors.js          # 各平台图片提取
├── gallery/                   # 预览与选择下载页
└── icons/
```

## 说明

- 部分图片 CDN 有防盗链或动态加载，若提取不全，可先滚动加载详情图再点「获取图片」
- 下载需授予浏览器下载权限；首次使用请允许
- Manifest V3，需 Chrome 109+
