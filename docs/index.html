电商图片提取下载

Chrome 浏览器扩展：在淘宝、京东、拼多多商家版商品详情页一键提取图片， 预览勾选后下载为 PNG。

查看源码 下载 ZIP

支持平台

  • 淘宝 / 天猫详情页
  • 京东商品详情页
  • 拼多多商家版与商品页

安装方式

  1. 打开 Chrome，进入 chrome://extensions/
  2. 开启右上角「开发者模式」
  3. 点击「加载已解压的扩展程序」
  4. 选择本仓库解压后的根目录（含 manifest.json）

使用说明

  1. 打开商品详情页，点击右下角「获取图片」
  2. 在新标签页预览并勾选需要的图片
  3. 点击「下载选中」，图片以 PNG 保存到本地
